# Agile User Stories

| ID | User Story | Acceptance Criteria | Priority |
|---|---|---|---|
| US-01 | As an Operations Manager, I want cancellation rate by reason so that I can prioritize process fixes. | Filters update totals; reasons reconcile to cancelled orders. | Must |
| US-02 | As a Fulfillment Manager, I want same-region vs cross-region delivery performance so that I can improve warehouse routing. | View shows shipment count, avg delivery days and late %. | Must |
| US-03 | As a Logistics Manager, I want courier SLA by region so that I can identify underperforming lanes. | Courier-region matrix available with time drill-down. | Must |
| US-04 | As a CX Lead, I want return reasons by category so that I can target quality issues. | Return counts and refund amounts can be grouped by category/reason. | Must |
| US-05 | As a Finance Analyst, I want refund-to-revenue % so that I can monitor leakage. | Delivered revenue excludes cancelled orders; refunds sum from return records. | Must |
| US-06 | As an Operations Manager, I want late-delivery trend by month so that I can detect capacity pressure. | Monthly trend displays shipment volume and late %. | Must |
| US-07 | As a Product Manager, I want COD cancellation performance so that I can evaluate a reconfirmation feature. | COD and prepaid cancellation metrics shown consistently. | Should |
| US-08 | As an Executive, I want a single KPI page so that I can understand performance quickly. | Primary KPIs plus trend and regional breakdown are visible. | Must |
| US-09 | As an Analyst, I want documented KPI definitions so that SQL and dashboard values reconcile. | Data dictionary and formula definitions exist. | Must |
| US-10 | As a QA/UAT user, I want filter outputs to reconcile to SQL so that I can trust dashboard results. | Sample selections reconcile within rounding tolerance. | Must |
| US-11 | As a Warehouse Manager, I want my site's late-delivery rate so that I can compare it with other warehouses. | Warehouse leaderboard sorted by late %. | Should |
| US-12 | As an Operations Manager, I want city-level late-delivery hotspots so that I can prioritize local action. | High-volume cities can be ranked by late %. | Should |
