# Interview Story: How to Explain This Project

## 60-second version
“I built an independent end-to-end Business Analyst case study for a fictional e-commerce company with 50,000 synthetic orders. The business problem was revenue leakage caused by cancellations, late deliveries, and returns. I modeled the order-to-delivery process, created BRD/FRD and user stories, built a relational SQL model, and wrote business-focused SQL analyses. I then created an interactive dashboard covering executive KPIs, fulfillment, returns and commercial performance. My analysis showed that COD orders had higher cancellation risk and cross-region fulfillment had a materially higher late-delivery rate. Based on that, I proposed same-region routing, COD reconfirmation, courier SLA scorecards and return-reason feedback loops, with UAT and an RTM to trace requirements through testing.”

## STAR framing
### Situation
Rapid e-commerce growth created fulfillment and customer-experience problems.

### Task
Identify the drivers of cancellations, late deliveries, and returns, then convert findings into actionable business/system requirements.

### Action
- Defined stakeholders, scope, KPIs and process maps.
- Built a normalized relational data model.
- Wrote SQL to segment performance by region, payment method, warehouse, courier and category.
- Created an interactive dashboard.
- Defined future-state requirements, user stories, acceptance criteria, UAT and RTM.

### Result
The analysis identified clear opportunities around cross-region fulfillment and COD cancellation risk and produced a prioritized future-state solution with measurable pilot targets.

## Interview questions to prepare
1. Why did you choose these KPIs?
2. How did you validate dashboard numbers?
3. What is the difference between BRD and FRD here?
4. Which requirement would you prioritize first and why?
5. What trade-off can same-region routing create?
6. How would you adapt the SQL for a production warehouse?
7. How would you conduct stakeholder elicitation if this were a real company?
8. How would you measure whether the pilot succeeded?
